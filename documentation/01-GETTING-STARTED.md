# 01 — Getting Started with QuietInk

Welcome to **QuietInk** ("Give Your Thoughts a Quiet Place").

QuietInk is a peaceful, distraction-free digital journaling platform designed to give you a calm, private, and beautiful sanctuary on the internet.

---

## What is QuietInk?

QuietInk is not a productivity tracker, task manager, or social network. There are no likes, followers, streaks to break, or aggressive notifications.

It provides:
- **Distraction-Free Writing Room**: Clean notebook canvas with customizable typography, autosaving, word metrics, and full **Solitude Mode**.
- **Calm Mode Atmospheres**: 8 atmospheric environments (Rain, Ocean Waves, Forest, Hearth Fireplace, Café, Midnight, Sunrise, Old Library) with real-time procedural soundscapes.
- **Ambient Sound Mixer**: Real-time Web Audio synthesizer for rainfall, ocean tides, crackling fireplace, piano chords, and wind.
- **Time Capsules**: Sealed reflections locked away until a chosen future date (1 month, 6 months, 1 year, or custom).
- **Letters to Future Me**: Thoughtful dispatches sent across time in a sealed envelope aesthetic.
- **Emotional Weather**: Gentle atmospheric moods (☀️ Bright, 🌤️ Calm, 🌥️ Cloudy, 🌧️ Heavy, 🌙 Quiet, 🌈 Hopeful).
- **My Quiet Garden**: A gentle visual garden that flourishes as you write, without shame or broken streaks.
- **Personal Library & Timeline**: Full-text search and chronological monthly timeline archives.

## Running Locally

### Prerequisites
- Node.js (version 18 or higher recommended)
- npm or yarn

### Quick Start Commands
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

---

## Where to Begin

1. **Personalize Your Site**: Open `src/config/siteConfig.ts` to set your site name, tagline, owner name, and email.
2. **Explore the Sanctuary**: Click **Start Writing** on the home page to experience the Writing Room.
3. **Turn on Ambient Sounds**: Click **Mixer** in the top navigation bar to turn on soft rain or piano chords while you write.
4. **Try Calm Mode**: Click **Calm Mode** to select an atmosphere like Rainy Window or Deep Forest.
